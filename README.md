# TypeScript Notes

A concise, practical set of TypeScript notes that I put together while learning. Written to be shared: read it top to bottom, or jump to the section you need.

## What's inside

The full notes live in [`notes.md`](./notes.md).

| 15 | Common pitfalls |

## Who is this for?

- Developers coming from JavaScript who want to learn TypeScript
- Anyone who wants a quick reference for TypeScript's core features
- Learners looking for common mistakes and best practices

## Prerequisites

- Basic JavaScript knowledge
- [Node.js](https://nodejs.org/) LTS (v18+) and npm, if you want to try the examples

## Quick start

```bash
# Clone the repository
git clone <your-repo-url>
cd <your-repo-folder>

# Optional: try the examples locally
npm install --save-dev typescript @types/node
npx tsc --init
```

Then open [`notes.md`](./notes.md) and start reading.
